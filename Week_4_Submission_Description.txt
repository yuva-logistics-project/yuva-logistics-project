This report describes a baseline predictive modelling and optimization framework for estimating parcel delivery duration. It defines delivery hours as the target variable and uses distance, weight, traffic level, weather, vehicle type, priority, and delivery zone as candidate predictors. A Random Forest regression model is proposed because it can capture nonlinear patterns and interactions without requiring a strictly linear relationship. The report documents preprocessing with numeric imputation and scaling, categorical imputation and one-hot encoding, a held-out test set, and five-fold cross-validation. Mean Absolute Error, Root Mean Squared Error, and R-squared are explained as complementary evaluation metrics. The included Python script implements the workflow and prints the resulting scores when run locally; no unexecuted model score is presented as a verified result. The report also proposes practical decision-support actions such as flagging shipments with elevated predicted delays, reviewing staffing and vehicle allocation by zone, testing route changes, and comparing cost and service trade-offs. Optimization recommendations are framed as pilots requiring real data, constraints, and human review. Since the training data is simulated, model performance is educational only and should not be used for live dispatch decisions without validation on representative historical records. The report treats model predictions as decision-support estimates rather than guaranteed delivery promises. It highlights that real-world evaluation should include representative data, clear prediction timing, relevant operational constraints, and error checks for different zones and shipment types. It recommends comparing the model with a simple baseline and recording model versions, test results, and limitations. Any operational pilot should be monitored against pre-agreed service and cost KPIs before wider adoption.
