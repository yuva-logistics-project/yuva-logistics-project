# Data-Driven Logistics Performance Analysis and Delivery Time Optimization Using Python

Prepared for the YuvaIntern Logistics Data Analyst Intern weekly tasks.

## Important data note
The included CSV is **simulated educational data**, not real company data. Charts and model results generated from it must not be described as real-world findings.

## Contents
- `Week_1_Logistics_Report.docx` — planning, scenario, KPIs, roadmap
- `Week_2_Logistics_Report.docx` — data collection simulation and preprocessing
- `Week_3_Logistics_Report.docx` — EDA and charts
- `Week_4_Logistics_Report.docx` — predictive modelling and optimization
- `simulated_logistics_shipments.csv` — reproducible 600-row synthetic dataset with deliberate data quality issues for Week 2
- `generate_data.py` — regenerates a clean synthetic dataset
- `week2_preprocessing.py` — cleaning example
- `week3_eda.py` — EDA and chart generation
- `week4_model.py` — model training and evaluation

## Setup
Use Python 3.10+ in a virtual environment, then install:
`pip install -r requirements.txt`

Run scripts from this directory:
`python week2_preprocessing.py`
`python week3_eda.py`
`python week4_model.py`

The model script prints actual evaluation metrics when executed. Record the observed output; do not invent scores.
